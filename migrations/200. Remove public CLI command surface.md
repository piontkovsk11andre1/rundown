# Remove public CLI command surface

This migration reduces the public CLI to the commands used by the simplified rundown runtime. Removed commands should disappear from help, command registration, public app surface, tests, and user-facing docs. Keep `run --all`, the separate `all` command, and `materialize` as multi-task execution surfaces.

- [x] Update `src/presentation/cli.ts` to remove public command registrations, imports, and mode constants for `agent`, `research`, `explore`, `translate`, `start`, `migrate`, `predict`, `snapshot`, `compact`, `test`, `revert`, and `workspace`, then add a `repair` command that opens the rundown repair agent while retaining `all` as the shorthand run-all command and `materialize` as the snapshot/revertable run-all surface.
